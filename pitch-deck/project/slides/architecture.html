Warden

05

Content is first opened up: white-on-white text in PDFs, HTML comments, tracked changes in Word, text inside images. Then disguises are removed: base64, invisible characters, lookalike letters. 122 rule patterns in 7 languages catch the obvious attacks in about 4 milliseconds. The classifier and memory handle the rest. Only content that is still uncertain goes to the LLM judge, which is optional. The session tracker catches attacks split across several messages. On the way out, the output guard checks what the agent tries to do.
