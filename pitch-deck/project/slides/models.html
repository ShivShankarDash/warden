Warden

06

Everything except the judge runs locally with no API calls. Laya is the main detector, served from a small Python sidecar. If it is not installed, Warden falls back to Meta's Prompt Guard 2, which runs in-process through ONNX. MiniLM embeddings power the memory, so a reworded version of a known attack is caught in about a millisecond. The judge is Claude Haiku 4.5 by default, also available through OpenRouter or OpenAI, and it only sees content the local models are unsure about.
