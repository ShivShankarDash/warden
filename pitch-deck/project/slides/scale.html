The cost table assumes a Claude Haiku 4.5 judge at about 2,000 input and 150 output tokens per call, roughly 0.28 cents. A cloud model on every scan costs 2,750 dollars a month at a million scans. Warden sends only about 21 percent of scans to the judge, measured on our 10K benchmark run, so the same traffic costs about 580 dollars. Fully on-prem with the judge off, API cost is zero at any volume. Moving the judge to Claude Haiku 5.5 would cut the middle column about ten times. Throughput: 2,339 samples in 363 seconds on one process, about 6.4 scans a second or 550 thousand a day. Policies are one YAML file per agent, and new memories sit on probation until seen again, so the system can't be poisoned. Hardware cost is not included.
